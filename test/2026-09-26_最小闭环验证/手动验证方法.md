# 手动验证方法：VLA 远程推理与动作执行最小闭环

本文档提供可复现的手动验证步骤，验证「树莓派 → Windows Relay → Ubuntu VLA」全链路。

## 0. 前置条件

- 三台主机已配置 SSH 免密访问；
- 三端已安装 Python 3 与 `websockets` 库；
- 代码文件已就位（见各仓库）。

| 文件 | 位置 | 作用 |
| ---- | ---- | ---- |
| `vla_server.py` | Ubuntu `~/work/vla/src/vla/server/` | 连接 B 服务端 |
| `relay.py` | Windows 本机 `src/relay/relay.py` | 中继（连接 A 服务端 + 连接 B 客户端） |
| `relay_client.py` | 树莓派 `~/robot/src/robot/comm/` | 连接 A 客户端 |

## 1. 依赖安装

```bash
# Windows（本机）
python -m pip install websockets

# 树莓派（PEP 668 环境需加 --break-system-packages）
ssh pi@192.168.2.30 "pip3 install --break-system-packages websockets"

# Ubuntu（若未安装）
ssh narwal@10.0.80.19 "pip3 install websockets"
```

## 2. 启动顺序

必须按「Ubuntu → Relay → 树莓派」顺序启动。

### 2.1 启动 Ubuntu VLA 服务端

```bash
ssh narwal@10.0.80.19 "cd ~/work/vla && nohup python3 src/vla/server/vla_server.py > /tmp/vla_server.log 2>&1 &"
```

确认监听成功：

```bash
ssh narwal@10.0.80.19 "cat /tmp/vla_server.log"
# 期望输出：VLA 服务端启动，监听 0.0.0.0:8443
```

### 2.2 启动 Windows Relay

```powershell
cd d:/work/vla_bridge
python src/relay/relay.py
```

确认日志输出：

```
Windows Relay 启动，连接 A 监听 0.0.0.0:9443
连接 B 目标：ws://10.0.80.19:8443
```

### 2.3 启动树莓派设备客户端

```bash
ssh pi@192.168.2.30 "cd ~/robot && nohup python3 src/robot/comm/relay_client.py > /tmp/pi_client.log 2>&1 &"
```

观察日志：

```bash
ssh pi@192.168.2.30 "tail -f /tmp/pi_client.log"
```

期望每 2 秒一轮：`发送观测` → `收到动作` → `发送执行 ACK`。

## 3. 验证判断标准

满足以下全部条件即为通过：

1. 树莓派日志出现连续的 `收到动作 action_seq=N`，序号递增；
2. Relay 日志出现成对的 `[A->B]` 与 `[B->A]` 转发记录；
3. Ubuntu 日志出现 `收到观测` → `返回动作` → `收到执行 ACK` 完整链路；
4. 三端 `device_id`、`session_id`、序号一致。

## 4. 停止与清理

```bash
# 树莓派
ssh pi@192.168.2.30 "pkill -f relay_client.py"

# Ubuntu
ssh narwal@10.0.80.19 "pkill -f vla_server.py"

# Windows：结束 python 进程
Get-Process python | Where-Object { $_.Path -like '*Python*' } | Stop-Process -Force
```

## 5. 故障排查

| 现象 | 排查方向 |
| ---- | ---- |
| Ubuntu 启动报 `address already in use` | 端口 8443 被占用，`ss -ltnp \| grep 8443` 找到占用进程并结束 |
| 树莓派连不上 Relay | 检查 Windows 防火墙是否放行 9443 端口；确认使用 `192.168.2.49` 而非 VMware 网卡地址 |
| Relay 连不上 Ubuntu | 检查 SecureLink 策略是否放行 `10.0.80.19:8443/TCP` |
| 树莓派 ping 不通 Windows | 正常现象（ICMP 被拦），TCP 连接不受影响 |
